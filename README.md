# 🏥 Hospital Management System

A Full-Stack Web Application developed to manage hospital operations like patient records, appointments, and administrative tasks efficiently.

---

## 🚀 Tech Stack

- Frontend: React, Tailwind CSS
- Backend: Java, Spring Boot
- Database: MySQL
- ORM: JPA / Hibernate
- Architecture: RESTful APIs, Layered Architecture

---

## ✨ Features

- Patient Registration & Management
- Appointment Scheduling
- Doctor & Staff Management
- CRUD Operations using REST APIs
- Responsive UI Design
- Backend & Frontend Integration

---

## 🏗️ Architecture

Controller → Service → Repository  
Layered architecture for clean and maintainable code.

---

## 📂 Project Structure

Frontend and Backend are integrated using REST APIs.
